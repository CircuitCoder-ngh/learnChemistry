Electron configurations

Atoms fill their orbitals in a fixed order, like guests checking in to a hotel. Learn the three house rules and you can write down any atom.

  • Fill orbitals using the Aufbau principle, Pauli exclusion and Hund's rule
  • Write full and noble-gas configurations using the periodic table as a map
  • Count valence and unpaired electrons
  • Write ions correctly, including transition metals, and spot the Cr and Cu exceptions

The electron hotel

In the last lesson, every electron got an address. Now we ask which addresses actually get used. An atom fills up the way a hotel does, and the hotel has three house rules.

Three rules build every atom. Aufbau: lowest energy first. Pauli: at most two in a box, with opposite spins. Hund: spread out in a subshell before pairing up.

Exam trap: 4s fills before 3d

The shell numbers do not simply count up. After 3p comes 4s, then 3d, then 4p. So potassium is $\mathrm{[Ar]\,4s^{1}}$, not $\mathrm{[Ar]\,3d^{1}}$. The chart in the story gives you the order: read along the diagonals.

The periodic table is a map

You do not need to memorize the filling order. The periodic table is already laid out in that order. Each region, or block, is named after the subshell being filled there. To write a configuration, start at hydrogen and walk along the rows until you reach your element.

Shorthand, exceptions and ions

Long configurations are tiring to write, and only the outer electrons do chemistry. So chemists use a shortcut, and they keep a few special cases in mind.

Worked example: sulfur, full and short

Write the full and the noble-gas configuration of sulfur, Z = 16. How many valence electrons does it have?

  1. Sulfur has 16 electrons. Fill in order: $\mathrm{1s^{2}}$ uses 2, $\mathrm{2s^{2}}$ brings it to 4, $\mathrm{2p^{6}}$ to 10, $\mathrm{3s^{2}}$ to 12.
  2. That leaves 4 for 3p, so the full form is $\mathrm{1s^{2}\,2s^{2}\,2p^{6}\,3s^{2}\,3p^{4}}$.
  3. Check the total: $2 + 2 + 6 + 2 + 4 = 16$.
  4. The first 10 electrons match neon, so the short form is $\mathrm{[Ne]\,3s^{2}\,3p^{4}}$.
  5. The outer shell is $n = 3$, with $2 + 4 =$ 6 valence electrons.

Worked example: a transition metal ion

Write the configuration of $\ce{Fe^{3+}}$. Is it paramagnetic?

  1. Start with the neutral atom. Iron is Z = 26: $\mathrm{[Ar]\,4s^{2}\,3d^{6}}$.
  2. Remove 3 electrons, highest $n$ first. Both 4s electrons go first, leaving $\mathrm{[Ar]\,3d^{6}}$.
  3. The third comes from 3d, leaving $\mathrm{[Ar]\,3d^{5}}$.
  4. Five d electrons take five separate boxes under Hund's rule, so 5 are unpaired, and it is paramagnetic.

Exam trap: first in, first out

Students write $\ce{Fe^{2+}}$ as $\mathrm{[Ar]\,4s^{2}\,3d^{4}}$ because 3d went in last. It is wrong. Once 3d holds electrons, 4s sits higher, so it leaves first. The answer is $\mathrm{[Ar]\,3d^{6}}$. Always write the atom first, then remove from the highest $n$.

For the exam, learn Cr and Cu. Other exceptions exist, such as Mo, Ag and Au, and your instructor will tell you if they count. The element next door to the rule-breaker usually behaves itself.

Check yourself

Pocket card

  • Filling order: 1s, 2s, 2p, 3s, 3p, 4s, 3d, 4p, 5s, 4d, 5p, 6s, 4f, 5d, 6p, 7s, 5f, 6d, 7p.
  • Capacity: s holds 2, p holds 6, d holds 10, f holds 14. Superscripts add up to the electron count.
  • Hund: singles first, with parallel spins. Pauli: at most 2 in a box, with opposite spins.
  • Shorthand: put the previous noble gas in brackets, then write the rest.
  • Exceptions: Cr is $\mathrm{[Ar]\,4s^{1}\,3d^{5}}$. Cu is $\mathrm{[Ar]\,4s^{1}\,3d^{10}}$.
  • Ions: write the atom first. Remove from the highest $n$, so 4s goes before 3d. Add to the next open place.
